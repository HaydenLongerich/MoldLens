MOLD BUSTERS - HACKATHON STARTER PACK

START WITH 00_START_HERE.pdf, then open either Job_Story.pdf.

Two illustrative jobs: one on-site inspection and one virtual assessment. Both include a readable job story, a structured JSON timeline, a de-identified reference report and source photographs. The virtual case also includes a silent 2m56s client-camera walkthrough.

THE CHALLENGE IS OPEN TO THE WHOLE BUSINESS
These cases are examples to build with. Teams may work on customer service, booking, report preparation, scheduling, follow-up, data quality or another useful part of the business. One focused working solution is enough.

WORKING WITH THE DATA
- Keep reference reports separate from inputs if evaluating report generation.
- Two cases are suitable for prototypes and worked examples; they are not a representative training set or an accuracy benchmark.
- Some source records disagree. Preserve uncertainty and flag mismatches instead of inventing missing facts.
- Recorded elapsed time between events is not measured staff labor time. Distinguish measured prototype performance from projected savings.
- The source video is low resolution. The still photos contain more visual detail; enlargement does not restore missing detail.
- This is an offline sample pack. Live access to company systems or APIs is not included.

SHARING EDITS
Client names, exact property addresses, postal code and original transaction IDs have been replaced or removed. Staff names use stable aliases. Identifying property-cover images, PDF links, attachments and document metadata have been removed. All 24 JPG photographs are retained unchanged; no EXIF data was present. Call audio and the full identifiable call recording are excluded. The walkthrough is video-only. Case dates and operational amounts remain for workflow context.
